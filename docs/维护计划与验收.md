# v0.3.0 维护范围与后续开发顺序

2026-11-15。当前维护目标：让开发者和现场接手人都能从同一套说明、设计导入结果和明确的验收要求继续工作。

## 本次已完成

| 项目 | 实现与检查 | 证据边界 |
|---|---|---|
| 首测离线入口 | `vna.py prepare` 与菜单 8 | 不连接仪器，不开启 RF，不生成可执行 profile |
| 设计导入 | XLSX A:I 或规范化 CSV；源 SHA256、表名、行号；公式拒绝 | 不把模型“通过”当作真实器件通过 |
| 搜索建议 | 合并频窗、按 QL 上限设置间隔、分段重叠、未知耗时保留空值 | 覆盖仅在偏移和 Q 假设内成立 |
| 现场缺项 | 空衰减/增益/功率、Q 含义、温度与操作人表 | 填表不会自动获得采集权限 |
| 人类说明 | 现场交接、首次降温路线、开发任务顺序 | 新同事不需访问旧聊天即可开始 |
| 回归验证 | 35 个离线单元/集成测试；真实设计表本地导入与源文件不变检查 | 无新增实机采集证据，原宏未重新部署 |

现有采集/导入/报告路径继续保留；电脑工具版本为 v0.3.0，仪器内部宏仍为 v0.2.2。没有自动更新 VNA 内部项目。

## 开发任务与通过条件

### P0：现场信息与无源基线

填写 site.local.json 及链路清单；确认源/接收最大电平、频段、温度日志和时间偏差。复核仪器身份、现有 RF/触发/宏状态，保存原设置；使用无源器件复现旧采集和校验。

通过条件：完整原始数据与读回设置一致，单扫和短重复扫成功，结束 RF OFF 读回明确。故障/强制终止/断网测试需要单独约定，不能从正常短测推断。

### P1：受监督的多段执行器

输入是计划、现场核算后的独立采集配置及身份约束；不得把空功率计划直接运行。复用 `vna.SCPI`、`Recorder` 和现有超时/不重试策略，避免维护第二套底层通信。

必须保存：源设计和计划 SHA256、segment_id、实际频率轴/复数 S21、计划/读回设置、开始/结束时间、温度来源、功率预算引用、校准状态与错误。分段新增元数据不能破坏已有 `report.inspect_run`、`verify` 和提交事件规则。

先离线假仪器验证段顺序、覆盖、读回不符停止和任意一段出错后停止；再用无源器件验收 1 段、3 个有重叠段。无重复触发、原始数据可独立复核后，才作低温完整搜索。执行时间长时同时考虑温漂，不能把耗时估算当作静态谱证明。

### P2：离线候选与 QL 拟合

输入已保存的数据，不直接触发仪器。实现候选发现、局部复数模型与背景/电缆延迟处理，并给出质量标记和失败原因；不要把采样点最小值重命名为拟合 f0。

通过条件：含已知真值和噪声的模拟曲线、背景/邻峰/无峰/欠采样测试，能识别无法可靠拟合的情形；真实重复扫结果可解释。Qi/Qc 的拓扑、校准和可辨识性另外验证。实测峰映射设计 pixel_id 保留不确定性和人工确认。

### P3：有监督功率依赖与受限跟踪

固定温度与核算上限，低到高的小步功率列表；人为确认后运行。任何参数改变重新核对实际设置与校准适用性，出现异常停止。初版不要自动寻找“最大可用功率”。

频率跟踪只在有限范围内调整中心；找不到峰、拟合失效、接近边界或漂移过快时保存并停止/提示。不得自动加功率或无界扩频。

### P4：长时自主记录

确认一个固定窗口后继续用原 v0.2.2 宏。依次验收人工启动/取消、当前磁盘容量与写入、短测导入校验，再验证关闭控制连接、物理断网和更长时间。每一种通过都记录具体时长和次数，不合并成笼统的“完全可靠”。

### P5：CW 与 FSW 独立工程

单独开发固定 CW 配置、FSW 身份/选件只读检查、触发 I/Q 保存和批次完整性校验。先电学暗态、再已知事件/遮光对照、再真实光响应。PPS 和共同 10 MHz 分别核对。不要把 FSW 的 `READ?` 等可能启动采集的查询放进“只读检查”。

FSW 本机逐次保存/掉线后继续批次调度尚未实现；先验收有限记录和保存，再设计断网自主运行。不能复用 VNA 内部宏验收来证明 FSW 自主能力。

## 维护约定

- 每次改动先说明范围、现场依赖、验证方法；每个开发阶段保留独立提交，完成后更新状态表。
- 对真实硬件的查询、设置、RF 开关、触发和宏加载分别区分；开发/CI 不访问内网仪器。
- 日常检查：`python3 -m unittest discover -s tests -v`、离线 demo、prepare 示例；GitHub Actions 在 Python 3.10/3.12/3.14 运行。
- 保持 stdlib 基础路径；新拟合依赖若必要，应解释用途、固定版本并提供离线安装方式，不影响原记录器。
- `private/`、`data/`、`work/`、`*.local.json` 不进公共仓库。实机证据由操作者按范围整理，不能上传内网参数或未经筛选的设计原表。
- 原生 VBA 源与可加载二进制配套维护；此次未改 VBA，因此不改其版本或冒称已部署。

接手人的第一个明确任务：**补齐现场链路表并完成无源基线，然后开发 P1 的 1 段/3 段执行与保存验收。**
