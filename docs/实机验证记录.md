# 2026-11-10 无源 LPF 实机验证

仪器：Agilent E5071C，固件 A.11.02。被测器件：操作员提供的 DC–1575 MHz 无源低通滤波器。没有接低温/KID 链路。

## 条件与结果

- 扫频 1–4 GHz，1601 点，IFBW 1 kHz，源功率 -30 dBm，平均关闭，未校准。
- 在首次测试前通过程序关闭并读回确认 RF OFF。
- 首次扫频遇到程序对完成标志的兼容问题：固件回复 `+1`，v0.1.0 只接受字符串 `1`。程序停止并确认 RF OFF，没有自动重触发。随后只读恢复当前仪器曲线，标记为恢复数据，保留原失败日志；恢复数据没有伪造精确采集完成时标。
- v0.1.1 改为数值判断，随后新的独立单次采集完整成功，得到 1601 个频点及 3202 个 Re/Im 数值，并保存 CSV、JSON、SVG。触发至数据读回约 1.95 秒（不是仪器纯扫频时间）。结束后 RF OFF 读回确认。
- 再进行每 5 秒一次、共 3 次的 monitor，三组数据均完整保存、SHA256 校验一致，结束后 RF OFF 读回确认。
- 1.3 GHz 的三次读数约为 -1.50155、-1.50066、-1.50139 dB，极差约 0.00089 dB。这里只描述该点在这三次短时间测量中的重复性，不代表绝对精度或长期稳定性。

形状与低通器件一致。**未校准结果包含电缆、转接器及仪器系统误差，不将其作为器件绝对插损、截止频率或阻带指标的验收。** 当前没有测量 DC–1 GHz，也不声称覆盖完整标称通带。
