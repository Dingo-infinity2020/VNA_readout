# E5071C 离线读出操作说明

适用版本：v0.1，Python 3.10+。第一次先用无源滤波器验证，再接 KID。下列 IP 均是示例。

## 1. 准备与接网

需要：电脑、Python、一根网线、必要时 USB-C 网卡、两根测试电缆、无源滤波器。程序无第三方依赖，可提前下载到不联网的电脑。

电脑与 VNA 后面板 LAN 口可以直接连接。选择与其他网络不冲突的网段，例如电脑 `192.168.50.1`、VNA `192.168.50.2`，掩码均为 `255.255.255.0`，直连口网关/DNS 留空。也可使用实验室已有网络。更改前记录原来的网络配置。

在 VNA 按 **System → Misc Setup → Network Setup → LAN Dialog** 查看实际地址；开启 Telnet/Socket Server。程序使用 TCP **5025**，不是浏览器和交互 Telnet 端口。不要点击 LAN RESET。

终端进入本仓库目录，执行：

```bash
python3 vna.py check --host 192.168.50.2 --timeout 5
```

`check` 只查询身份及当前设置，不触发、不改 RF。应返回 E5071C。需要防止接错同型号仪器时，可额外指定 `--serial 你的仪器序列号`。

网络故障时检查：当前 IP、网线灯、两端网段、远程服务及校园网络隔离。不要不断重试触发命令。

## 2. 第一次用滤波器测量

1. 在 VNA 前面板关闭 RF，断开低温/KID 链路。
2. 接线：**Port 1 → 电缆/N转SMA → 滤波器输入 → 滤波器输出 → 电缆/N转SMA → Port 2**。确认滤波器实际频段和功率额定值，不能把有源器件当无源滤波器。
3. 复制 `configs/filter.json` 为 `configs/filter.local.json`，需要时修改起止频率（Hz），仍保持在 1–4 GHz 内；默认源功率 -30 dBm。这个值只用于已确认耐受的无源器件，不是 KID 通用安全功率。
4. 执行：

```bash
python3 vna.py capture --host 192.168.50.2 --profile configs/filter.local.json --allow-rf --notes "filter first test, no calibration"
```

5. 正常输出应包括 `1601 points saved` 和 `RF OFF confirmed`。打开生成的 SVG 核对通带位置，CSV 可用 Excel 或文本编辑器查看。
6. 同一条件再测两次，比较通带位置、幅度和曲线重复性。未校准只能验证采集和相对响应，不能据此承诺滤波器绝对插损精度。

滤波器模式会关闭误差校正、功率斜率和 Port 1 功率校正，设置线性扫频、关闭平均，设置 Channel 1 单条 S21 轨迹。程序不执行 Preset，不删除校准系数，但会改变当前配置。实验前请人工保存已有的仪器状态。

v0.1 源功率范围限制为 -55 至 -20 dBm，仅用于减少误操作；仍须核对器件与链路。需要其他功率时先评估并修改程序，不静默放宽限制。

## 3. 手动校准与校准后采集

校准参考面放在最终 SMA 电缆末端，包含前面的 N 电缆和 N→SMA 转接器。两末端为 SMA 公头时，需要可匹配的母口标准件。校准后不拆转接器，避免改变电缆姿态。

**单向低温链路含隔离器/放大器，v0.1 校准模式只接受正向 Thru Response（RESPT）。不接受 SOLT2/TRL2 等需要反向扫端口的完整双端口校正。** 只显示 S21 并不能阻止完整双端口校正进行反向激励。

操作顺序：

1. 先定实际频段、点数、IFBW、源功率，设置线性扫频、平均 OFF，Channel 1 Trace 1=S21，其他多余轨迹不参与测量。
2. 在室温参考面接已知 Thru，选择仪器的正向传输 Response/Thru 校准，按前面板指引完成。供应商标准件定义必须匹配。不要通过低温放大链做普通被动 Thru 校准。
3. 验证 Thru 幅相和重复性；如果有独立已知衰减器，再作独立检查。Thru 自洽不代表独立精度验证。
4. 用 Save/Recall 的 **State & Cal** 保存状态及校准，复制到实验数据目录，同时记录校准件、参考面和时间。
5. 复制 `configs/kid.example.json` 为 `configs/kid.local.json`，填写实际频率、点数、IFBW、经链路预算确定的源功率、真实 `cal_id`。示例的 `power_dbm=null` 故意不能执行。
6. 校准模式下程序不会改频率、点数、IFBW 或功率；读回与配置不一致就停止。会设置单条 S21、触发、传输和 Hold 源端口行为。校准类型不是 RESPT 或无法查询时停止，不降级为未校准运行。

```bash
python3 vna.py capture --host 192.168.50.2 --profile configs/kid.local.json --allow-rf --notes "dark, stable cold stage"
```

Thru Response 只修正部分传输响应，不等于完整失配修正；室温末端校准也不消除其后的低温电缆、隔离器、放大器和衰减器响应。源功率与芯片功率必须分开记录。改频率/点数/功率后重新检查并酌情重校准，不假定旧校准对任意设置都有效。

## 4. 降温与暗态重复采集

首次 KID 运行前补齐：接线方向、各温级输入衰减、输出增益/损耗、放大器供电及允许电平、目标和最大芯片输入功率。先核算再接器件。v0.1 不自动控制制冷机。

| 场景 | 默认建议 |
|---|---|
| 降温跟踪一个已知谐振 | 固定窗口，每 60 秒一次 |
| 稳定低温暗测试 | 每 30 秒一次，先连续 30–60 分钟 |
| 更细的慢漂移 | 实测扫频耗时足够短后改为每 10 秒 |
| 尚无谐振或未知频带 | 先宽带概览，再人工缩小窗口 |

```bash
python3 vna.py monitor --host 192.168.50.2 --profile configs/kid.local.json --interval 60 --count 60 --allow-rf --notes "cooldown; see external temperature log"
```

`--interval` 是每轮开始之间的目标间隔，`--count` 是保存次数。每轮完成后留余量，扫得慢会自动延长周期。终端显示保存进度。最后一次后立即结束，不再空等一个周期。

第一版一次运行只用一个固定频段，不自动换窗口或调功率。降温时约每 15 分钟、暗测试约每 30 分钟可暂停精扫并手动做概览；换配置后重新核验校准并开新运行目录。概览时间是监测间隙，需要保留。

1–4 GHz、1601 点的单次全带间隔约 1.875 MHz，会漏窄谐振，仅用于概览。精扫间隔应小于线宽的 1/10；例如 3 GHz、加载 Q=1e5 时线宽约 30 kHz，1 MHz/1601 点间隔约 625 Hz。对未知频率的窄谐振，应人工分窗搜索或后续增加分段扫频，不把一次全带概览当作找全谐振。

温度：`--temperature-k` 只记录操作员在开始时输入的静态值，并标记 `manual_start_value_not_live`，**不会持续读取温度**。降温过程中请使用独立温度日志和 UTC 时间关联，避免把起始温度当作整段真实温度。无温度数据时记 unknown。

重复扫频及 Hold 不是持续谐振单音读出。比较功率/温度时维持相同触发节奏和稳定等待条件；不要将间歇扫频直接解释为连续单音稳态。

## 5. 数据、存储频率与备份

**每次真正触发并完整返回的扫频都保存，不抽样丢弃。** CSV 含 Re/Im，幅相是由复数值计算的派生列。不要只保留截图，不要将只有 S21 的 CSV 改后缀伪装成完整 .s2p。

元数据包含软件版本、仪器身份、请求和实际设置、校正开关、cal_id、起止 UTC 时标及耗时。预览只是幅度图；完整相位保存在 CSV。`SDAT` 是仪器当前校正/端口延伸等处理后的复数 S 参数，不是接收机原始 ADC 数据。

每个 CSV 先写临时文件并同步落盘，再生成 JSON，最后写 `committed` 事件。用 JSON 中的 `csv_sha256` 可验证 CSV 是否改变。异常留下 `.tmp` 或缺 JSON/提交记录的文件时，先隔离检查，不能当作完整扫频。

1601 点 CSV 的实际大小以本机文件为准：

> 每天空间 ≈ 单个 CSV+JSON+SVG 大小 × 86400/实际周期 × 每轮器件数。

先预留 10 GB；程序发现剩余空间低于 100 MB 时停止新增触发。每小时和实验结束后将整个运行目录复制到第二介质并校验。v0.1 不自动备份、自动删除或上传数据。

GitHub 是公共代码仓库；不要提交真实实验数据、仪器状态文件、内网 IP/密码。个人配置命名为 `*.local.json`。

## 6. 停止、异常与恢复

- 正常结束和 Ctrl+C：尝试 RF OFF 并读回确认，不恢复先前 RF ON 状态。
- 超时或断连：连接标记为不可用，**不重试触发**，不复用不确定回复。RF 关闭可能无法送达，请人工确认前面板。
- 写盘/解析/仪器错误：停止后续采集，保留已有文件和事件。配置期间发现错误应在 RF 开启前停止。
- 开始前已有错误队列时，程序将其读出记录并停止；读取错误队列会消耗其中条目。`check` 不读取/清除错误队列。
- 重新运行会创建新目录。先查原因、核对配置及 RF 状态，再恢复，不覆盖旧数据。
- 网络正常而曲线异常时，先检查接头、方向、供电、过载、频段和校准；不要自动加大功率。
- 程序被强制终止、电脑断电或网线断开时无法保证关闭 RF。

## 7. 第一版验收

| 项目 | 通过标准 |
|---|---|
| 只读连接 | 仪器身份正确，设置能够读回 |
| 无源器件单扫 | 实际频率和点数正确；复数数组完整；通带位置合理 |
| 重复采集 | 3 次单扫及短时间 monitor 均无重复覆盖/缺文件 |
| 结束行为 | 正常结束/Ctrl+C 后 RF OFF 读回成功 |
| 故障行为 | 超时/断连不自动重触发，提示人工核对 RF |
| 手动校准 | State & Cal 和验证曲线留存，校准类型可核验 |
| KID | 链路功率已核算，低温下重复曲线可解释 |

模拟测试只能验证软件边界，真实端口方向、输出电平和固件行为仍需现场验收。当前阶段不据此声称 KID 科学测量已通过。
